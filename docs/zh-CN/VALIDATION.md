# 运行检查与已测试环境

[English](../en/VALIDATION.md) · [首页](../../README.zh-CN.md)

按[试玩指南](../../examples/whitebridge/README.zh-CN.md)启动后，这一页帮助你判断配置是否正常。修改代码、换电脑或准备连接直播间时，也可以重做对应步骤。

## 先看能不能玩

- 用一个测试身份加入阵营、发 `参战`，确认有自己的士兵和反馈。
- 用 `2` 让自己的部队后退，再用第二个身份加入另一方。
- 点一次模拟礼物，确认对应的单位或效果出现。
- 开声音，检查音乐和音效；暂停后再继续，最后用 `Ctrl+C` 停止服务。

这些步骤只用本地消息，不需要真实礼物。

## 修改代码后运行检查

在项目根目录运行：

```sh
npm test
npm run docs:check
npm run privacy:check
```

`npm test` 检查去重、部队归属、战斗、复活、对话调度等规则。文档检查找缺页和坏链接；隐私扫描查常见密钥与私人路径。画面和声音仍要实际试玩。

需要生成 OBS 配置或源码包时运行：

```sh
npm run obs:export
npm run release
```

文档、扫描和打包命令需要 Python 3.8+。`npm run test:full` 是更大的历史回归集合，其中部分场景沿用旧规则；它没有被计入 0.3.0 的发布测试结果。

## 接外部服务后检查

| 新接的部分 | 应该看到什么 |
| --- | --- |
| AI | 一次实际请求成功，生成的回复与提问对应，设置页记录用量 |
| 语音和角色 | 能听见同一段回复，口型跟随音频，停止后不继续播放旧句子 |
| B站弹幕 | 平台接入页出现消息记录，游戏里对应玩家得到反馈 |
| B站礼物 | 赠礼账号获得对应效果，同一事件重发不重复奖励 |
| OBS | 录制文件只有游戏与指定音频，切电脑窗口不会带进其他画面 |

具体配置见 [AI 与语音](AI-AND-MEMORY.md)、[B站与 OBS](BILIBILI-AND-OBS.md)。模型和平台的自动测试使用模拟响应，因此这里需要你自己的服务与房间。

## 0.3.0 的测试记录

发布时使用 macOS、Node 24.11.1、Python 3.8+：维护中的 218 项自动测试通过；全新目录可以启动并完成本地参战与模拟礼物；检查了文档链接、素材校验值、OBS 模板结构和打包清单。

这个记录对应 0.3.0，不代表所有设备的直播效果。Windows/Linux 全流程、多人高峰、长期无人值守、各账号实际推流仍需要测试。可选语音安装器检查了安装计划，没有为这一版本重新下载整套权重测试全新安装。
