# 把游戏接到 B站直播间

[English](../en/BILIBILI-AND-OBS.md) · [首页](../../README.zh-CN.md)

先完成[本地试玩](../../examples/whitebridge/README.zh-CN.md)。接下来要连接两个方向：**B站把弹幕和礼物发给游戏；OBS 把游戏画面和声音发给 B站。** OBS 是推流软件，推流就是把直播视频发送到平台。

## 1. 准备自己的房间和应用

开播权限和读取互动消息的权限需要分别准备。平台入口与条件可能变化，申请时以 [B站直播开放平台](https://open-live.bilibili.com/)和[官方文档](https://open-live.bilibili.com/document/849b924b-b421-8586-3e5e-765a72ec3840)为准。

1. 用自己的 B站账号完成平台要求的实名和直播间开通，确认当前账号与所在地允许开播。
2. 在直播开放平台申请开发者入驻，用途填写实际的弹幕、礼物互动玩法。
3. 获批后保存 Access Key ID 和 Access Key Secret，并创建应用、记录 `app_id`。这两项密钥用于让程序证明它是你的应用。
4. 按平台当前流程取得主播身份码，记录直播间 `room_id`。身份码用于绑定主播，不是网页登录 Cookie。
5. 按控制台要求完成应用测试、上传和审核；测试期可能只允许访问自己的直播间。

密钥只填写到本机设置页。遇到申请问题，可以提供去掉密钥的报错截图；不要把它们放进公开 Issue。

## 2. 接收第一条真实弹幕

游戏运行时打开 [http://127.0.0.1:4391/settings.html](http://127.0.0.1:4391/settings.html)，在「B站 · 开放平台授权」中填写资料，点击「保存并连接」，然后打开「平台接入」页。

这个页面里的**收据**是消息处理记录。用它确认一条消息有没有到达，以及是否被执行。

在自己的 B站房间发送 `加入人族`、`参战`、`2`。应该依次看到加入反馈、自己的兵、部队后退，同时收据页能找到对应消息。未开播房间能收到哪些事件由平台决定；若收据里没有消息，先解决连接或权限，暂时不要改派兵规则。

## 3. 配置礼物效果

在设置中单独开启「允许真实礼物进入战场」。这个选项让收到的赠礼事件产生游戏效果，不会替你购买礼物，也不会开启推流。

把当前房间的礼物 ID 与游戏效果对应起来。随包菜单提供六项示例绑定；真实名称、价格与可售范围以你的房间和收到的事件为准。示例里的礼盒图标是通用图标。

本地模拟礼物调好后，再测试真实连接。若选择用一份低价礼物测试，检查它只生效一次，部队归属赠礼的观众。重连时重复收到同一事件，也不应再次出兵。

## 4. 用 OBS 输出游戏

安装 [OBS Studio](https://obsproject.com/)。新建场景，添加[浏览器源](https://obsproject.com/kb/browser-source)，填入下面一个网址：

```text
http://127.0.0.1:4390/?side=demon&broadcast=1
http://127.0.0.1:4390/?side=human&broadcast=1
```

前者以魔族视角取景，后者以人族视角取景。宽设为 **1920**、高 **1080**，先用 **30 FPS**。4390 是提供给观众的画面；你平时用的 4391 是带操作控件的管理页。

关闭浏览器源的「不可见时关闭源」和「场景激活时刷新」。锁定来源位置，关闭桌面音频和麦克风，仅保留游戏浏览器音频。场景中只放游戏源，就不会随着你打开别的电脑窗口而切换画面。

也可以在项目根目录运行 `npm run obs:export`，从 OBS 的「场景集合 → 导入」载入 `.local/obs/demon.json` 或 `human.json`，再检查来源和声音。

OBS 的推流地址、密钥或平台登录方式，按账号当前提供的入口配置。项目无法替账号取得平台未开放的推流权限。

## 5. 录一段，再开始直播

先本地录制一小段：发兵、放一个事件、播放声音，再切换电脑窗口和桌面。播放录制文件，确认只有游戏和指定音频。

设置标题、封面和分区，检查游戏正在运行后，在推流软件开始直播。另一设备打开房间，检查弹幕操作、声音和卡顿。若画面卡，依次查看本地游戏、OBS 渲染/编码掉帧、上传网络和观众缓冲，从最先异常的环节处理。

只用游戏浏览器源仍需要服务持续运行。电脑睡眠、关闭游戏服务、切换 OBS 场景或增加其他捕获源都会影响输出。

## 6. 结束直播

先停止推流，确认房间已离线，再在项目终端按 `Ctrl+C` 停止游戏。下次启动会先暂停，需要重新检查连接与礼物开关。

## 其他平台

小红书的电脑开播验证码和串流密钥用于发视频，不能直接当作弹幕、礼物接口。当前项目只有供外部程序投递事件的接收协议，还缺可直接使用的授权采集器。YouTube、Twitch 也需要另写适配器；目前不要把这几项当作开箱即用功能。
