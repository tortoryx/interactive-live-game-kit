# 介绍你做出来的版本

[English](../en/SHARING.md) · [首页](../../README.zh-CN.md)

如果你用这个工具包做了一个新玩法，介绍时先让别人看见观众能做什么。一个从发送弹幕到游戏发生变化的短片，比功能名列表更容易理解。

## 录一段别人看得懂的演示

选择一条互动，把输入和结果放在同一段画面里。例如观众发「修补」，城墙恢复了多少血；或者一位玩家加入阵营，自己的头像将军跑进战场。再展示一处与你原来的版本不同的玩法。

本地测试画面标为「本地试玩」即可；真实直播片段中涉及观众昵称和头像时，先处理好展示许可或做匿名化。

录制时使用 [OBS 指南](BILIBILI-AND-OBS.md)中的独立游戏画面源。需要拍设置过程时，另外录制不含密钥的演示配置。

## 给想继续体验的人一个入口

项目介绍里说清三件事：观众怎样参与、你的版本改了什么、在哪里能试玩或下载。使用 AI 解说、平台账号或额外素材时，把配置要求放在下载说明里。

你可以在 README 中这样署名，并接着写自己的改动：

> 本项目基于 [Interactive Live Game Kit](https://github.com/tortoryx/interactive-live-game-kit)。我把示例改成了……观众可以通过……参与。

上面是可改写的句式。项目代码的 MIT 许可和素材各自的署名仍需保留，具体见[第三方内容与许可](THIRD_PARTY_NOTICES.md)。

## 分享源码

按[运行检查](VALIDATION.md)确认下载后能启动，再按[数据管理](SECURITY.md)核对要发布的文件。准备给陌生人使用时，最好让没有接触过项目的人只看你的 README 跑一次，把他卡住的步骤补上。
