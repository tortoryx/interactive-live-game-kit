# 一起改进这个项目

[English](../en/CONTRIBUTING.md)

欢迎分享新玩法、修复问题、补教程或接入新平台。不写代码也可以参与：告诉我们按教程卡在了哪一步，或者怎样重现一个试玩问题。报告问题时附上系统、版本、操作步骤和相关报错。

游戏功能放在 `examples/whitebridge/`；教程与工具放在 `docs/` 和 `scripts/`。下面是提交代码修改时需要做的检查。

先 `npm ci`、`npm test`、`npm run docs:check`，再本机启动复现。请附上你改动的具体体验、合成测试输入、验证方式和尚未解决的问题；不要贴真实观众记录或平台凭证。

保持权威边界：画面只是展示，游戏服务器控制伤害、归属和收据；模型只能返回经过校验的有限动作。新增平台需要独立适配器与重复事件、错误房间、断线重连测试，通过平台提供的授权方式连接。

新增素材请提供作者、出处、许可和改编说明。更改游戏体验要实际观察一次。新增公开文件后人工审阅，再运行 `python3 scripts/release.py manifest` 更新发版清单，随后扫描和打包。

在 Pull Request 中说明改动后的效果和试玩步骤；画面变化可以附上使用测试身份录制的短片。

翻译请遵循[语言清单](../LANGUAGES.md)，保持命令、功能限制和隐私边界一致。只翻译首页不能标为完整版本；文档翻译不等于游戏 UI 或区域平台已适配。
