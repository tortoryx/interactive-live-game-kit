# 第一次试玩：从下载到派兵

[English](README.md) · [项目首页](../../README.zh-CN.md)

你将在自己的电脑上运行「人魔争霸」，用页面里的测试弹幕扮演观众。先不接直播平台，也不需要 AI 密钥。

## 1. 下载和安装

1. 回到[仓库首页](../../README.zh-CN.md)，点击绿色 **Code → Download ZIP**，解压到一个容易找到的文件夹。文件夹里应该能看到 `package.json` 和 `scripts`。
2. 安装 [Node.js](https://nodejs.org/) **24.11 或更新的 24.x**。它是运行游戏服务的程序，安装时会一起带上 `npm`。
3. 打开终端。Mac 上可以用 Spotlight 搜索「终端」；Windows 上打开 PowerShell。输入 `cd `（后面有空格），再把解压后的项目文件夹拖进去，按回车。路径有空格时，用一对英文双引号包住路径。
4. 依次运行下面两条命令，第一条完成后再运行第二条：

```sh
npm ci
npm start
```

`npm ci` 首次需要联网下载依赖。看到终端提示 `Open http://127.0.0.1:4391/ to play` 后，用浏览器打开 [http://127.0.0.1:4391/](http://127.0.0.1:4391/)。这个地址指向你的电脑。

已验证的运行环境是 macOS。Windows、Linux 可以从相同的 Node 命令开始，但尚未完成对应环境的整套测试；本机语音另有系统要求。

## 2. 派出第一名士兵

1. 点击页面上方的「继续」，让战场开始运行。
2. 找到底部的测试弹幕栏，身份保留「测试玩家」。
3. 输入 `加入人族` 并发送，再输入 `参战` 并发送。
4. 你应该看到派兵反馈，以及带有这个测试身份标记的士兵。接着发送 `2`，观察自己的部队后退。
5. 把身份切换成「试玩乙」，发送 `加入魔族`、`参战`。现在你可以从两个观众的角度试互动。

底部的「模拟礼物 · 不扣费」可以试出兵和其他效果。它只改变本地游戏，不会购买礼物。点击「开启声音」听音乐和音效；未配置 AI 和语音时，右下角主持人不会自动开口。

## 3. 观众可以发什么

| 弹幕 | 作用 |
| --- | --- |
| `加入人族` / `加入魔族` | 选择阵营；没选时会自动分配 |
| `参战` | 免费派一名士兵，可继续发送，没有 30 秒参战冷却 |
| `1` / `2` / `3` / `4` / `5` | 前进 / 后退 / 攻击 / 守护 / 捡附近补给 |
| `自立门户` | 建立以自己头像为将军的新阵营；将军只有一条命 |
| `加入X族` | 加入已有玩家阵营，把 X族 换成屏幕上的名字 |
| `复活` | 查询自己阵亡部队需要的救援额度 |
| 屏幕上显示的八字咒语 | 触发对应事件；同一观众每 30 秒可用一次 |

指挥命令只控制当前身份自己的部队。存活部队会跨回合保留，首领换代不让它们自动满血。人族和魔族每分钟各有一支较弱的系统援军，观众也能继续派自己的队伍。

## 4. 停下来，下次再玩

「暂停」暂停战场；**关闭网页不会关闭后台服务**。结束试玩时，回到运行 `npm start` 的终端，按 `Ctrl+C`。下次在同一文件夹运行 `npm start` 即可，默认仍从暂停状态开始。

存档和个人配置位于项目的 `.local/` 文件夹。需要清空时先停止服务，再备份或移走它；这样也会移走已经填写的平台连接配置。

## 遇到问题

| 现象 | 先检查什么 |
| --- | --- |
| 找不到 `npm` | Node.js 是否安装完成；重新打开终端，运行 `node --version` |
| 提示找不到 `package.json` | 是否进入解压后的项目根文件夹，而非它外面一层 |
| 提示 `EADDRINUSE` | 同一游戏可能已经在运行；回到原终端停止它，不要重复启动 |
| 页面打不开 | 启动终端是否仍在运行，是否显示了错误 |
| 没有声音 | 点击游戏声音开关，再检查浏览器标签页和系统音量 |
| 看不到魔女或没有解说 | 这是单独配置的功能，按下面的主持人指南安装 |
