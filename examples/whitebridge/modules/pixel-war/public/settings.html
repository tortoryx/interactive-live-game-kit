解说语音 · 本地女声

可选本机 Qwen3-TTS 固定参考音色，只朗读解说内容。先按项目语音指南安装模型。字幕和口型跟随真实音频播放；开场自动预热，冷启动需要额外时间与数 GiB 内存。繁忙时可能更慢；内存不足会暂停配音并保留字幕，不会自动换回其他音色。空闲 120 秒卸载，不采集麦克风或桌面声音，无语音 API 费用。

也可自行配置下方云端方案；仅云端需要百炼 API Key。

云端语音才按百炼字符单价另行计费；本机模式不产生此费用。实际合成请求计入字符上限；预热、排队和内存不足未执行合成时不扣字符。语音失败保留字幕，界面显示原因。
